# Retiros

App local simple para anotar retiros de dinero del local.

## Qué hace

- Registra fecha, monto, método y nota.
- Métodos: efectivo o tarjeta.
- Muestra total del día y del mes.
- Panel mensual con selector de mes.
- Resumen por efectivo/tarjeta.
- Historial con opción de eliminar.
- Exporta e importa respaldo JSON.

La base de datos queda en el navegador mediante IndexedDB.
